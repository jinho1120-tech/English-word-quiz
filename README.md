# English Word Quiz

개인별 단어장과 퀴즈, 오답 복습, 발표 대본 훈련을 제공하는 공개 회원용 영어 학습 서비스입니다.

## 기술 구성

- Next.js / React / TypeScript
- PostgreSQL + Drizzle ORM (가족·자녀·단어·보상 데이터)
- Better Auth + PostgreSQL (부모 회원, 로그인, 세션)
- Gemini API (사진 단어 추출 및 듣기 퀴즈 뜻 채점)
- Azure Speech (영어 단어 듣기용 신경망 TTS, 브라우저 음성 합성 대체 지원)

## 계정 구조

- 부모는 이메일과 비밀번호로 가입하고 로그인합니다.
- 가족 대표 부모는 다른 부모의 이메일을 초대해 공동 관리자로 등록할 수 있습니다. 초대받은 부모는 자기 계정으로 가입 또는 로그인한 뒤 초대를 수락합니다.
- 공동 관리자는 각자 다른 기기에서 같은 가족의 자녀·단어장·학습·쿠폰을 관리합니다. 공동 관리자 초대와 해제는 가족 대표만 할 수 있습니다.
- 부모 계정 아래에 여러 자녀 프로필을 만들 수 있습니다.
- 자녀는 별도 이메일 계정 없이 접속 코드 + PIN 또는 QR 코드로 자기 기기를 최초 등록합니다.
- 등록된 자녀 기기는 자녀 전용 보안 세션으로 자동 로그인되며, 부모가 원격으로 접속을 해제할 수 있도록 설계합니다.
- 부모와 해당 자녀는 같은 자녀 단어장을 관리할 수 있지만, 다른 자녀의 데이터에는 접근할 수 없습니다.
- 쿠폰 발행 여부, 쿠폰 종류, 보상 조건, 부모 전화번호는 부모가 설정합니다.

세부 보안·인증·데이터 설계는 [가족 계정 설계 문서](docs/family-accounts.md)를 참고하세요.

## 환경변수

Vercel 프로젝트의 **Settings → Environment Variables**에 등록합니다.

- `DATABASE_URL`: Vercel에서 사용하는 이 서비스 전용 PostgreSQL 연결 문자열. 기존 `word-test` 가족용 DB와 절대 공유하지 않습니다.
- GitHub Actions에서 DB 초기화를 실행할 때는 같은 전용 Neon 연결 문자열을 저장소 비밀값 `ENGLISH_WORD_QUIZ_DATABASE_URL`로 등록합니다. `Neon-lime-jacket` 가족용 DB 주소를 넣으면 안 됩니다.
- `BETTER_AUTH_SECRET`: 32바이트 이상의 무작위 비밀키
- `BETTER_AUTH_URL`: 배포된 서비스의 기본 URL
- `GEMINI_API_KEY`: Gemini API 키
- `AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION`: Azure Speech 설정

실제 비밀값은 Git에 커밋하지 않습니다.

## 현재 구현 범위

- 부모는 자녀별 과목과 단어장을 관리하고, 자녀는 자기 기기에서 학습합니다.
- 자녀와 부모 모두 단어장 사진을 AI로 분석해 단어·뜻·예문을 추출하고, 결과를 확인·수정한 뒤 일괄 저장할 수 있습니다.
- 퀴즈는 기본 단어 입력과 발음 듣기 두 종류입니다. 기본 퀴즈는 영어 철자를 정확히 비교하고, 듣기 퀴즈는 영어 철자와 한국어 뜻을 함께 입력받아 기존 `word-test`와 같은 기준으로 Gemini가 뜻·품사를 채점합니다.
- 기본 퀴즈 힌트는 예문 속 정답 가리기 또는 첫 글자·글자 수 표시이며, 듣기 퀴즈 힌트는 첫 글자와 한국어 뜻을 표시합니다. 듣기 음성은 Azure Neural Voice, 목소리 선택 및 느리게 듣기를 지원하고 Azure 설정이 없으면 브라우저 음성 합성으로 대체합니다.
- 문장 퀴즈, AI 회화, 발음 평가 기능은 초기 버전에서 제외합니다.
- 오답 복습과 최근 30일 퀴즈 응답 수·정답 수·정답률·과목별 통계를 제공합니다.
- 퀴즈 응답 이력은 자녀별로 기록하며, 단어 수정/삭제 후에도 학습 통계의 단어·과목 이름을 보존하도록 스냅샷을 저장합니다.

## 데이터베이스 초기화

Drizzle 초기 마이그레이션은 `drizzle/0000_lively_luke_cage.sql`(앱 테이블 13개)과 `drizzle/0001_wise_iron_patriot.sql`(Better Auth 테이블 4개)로 생성되어 있습니다. Neon의 전용 데이터베이스 연결 문자열을 GitHub 저장소 비밀값 `ENGLISH_WORD_QUIZ_DATABASE_URL`로 등록한 뒤, 기본 브랜치에 병합된 **Apply Neon database migrations** 워크플로를 확인 입력과 함께 수동 실행하면 두 마이그레이션을 적용하고 Better Auth 스키마를 검사합니다. 아직 실제 Neon DB에는 적용하지 않았습니다.

## 데이터 격리 원칙

- 기존 `jinho1120-tech/word-test` 저장소와 가족용 데이터베이스는 수정하지 않습니다.
- 가족용 데이터는 이 서비스로 복사하거나 가져오지 않습니다.
- 부모 작업은 Better Auth 세션에서 확인한 소유자 ID로 범위를 제한합니다.
- 자녀 작업은 서버가 검증한 자녀 기기 세션으로 범위를 제한합니다.
- 브라우저가 전달한 부모 ID, 자녀 ID, 프로필 이름은 인증 증거로 신뢰하지 않습니다.
